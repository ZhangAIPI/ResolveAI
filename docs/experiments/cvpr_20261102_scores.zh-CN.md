# 临时结论评分：共同候选题上的标签命中

2026-11-02 16:20 EST。这份报告给出现在可以核查的临时分数，不是正式证据充分性评分。

## 题目与判分

固定使用四个模型均完成三个设置的同一批 **209个题族**，每族只选Sufficient版本一次。包括153个状态题和56个身份对照题；不把四种访问版本当成四个独立实物样本。总共有252个带构造标签的候选族，因Qwen3.5尚未跑完，本次只比较共同完成部分。另226族身份未知，不加入分数。

每个构造标签为Supported或Refuted。模型结论与它相同记1，否则记0；Need more evidence和未提交结论都留在分母，不能通过不回答缩小分母。例如“目标拉链有变形齿”，对应原数据为正常样本，构造标签为Refuted；回答Refuted计入标签命中。

这些Sufficient题按构造意图初始证据已经齐全，用来检查基础判断和交互表现，不是主动获取缺失证据的总分。图像是否真的足以判断尚待独立审核，所以本报告严格称为**构造标签命中率**。它不能证明弃答一定错误。

该批标签分布为103个Supported和106个Refuted；始终选择多数类的标签命中率为50.7%。模型和题目版本、共同题族ID、分任务计数及未提交数量保存在[机器可读记录](../results/cvpr_20261102_candidate_scores.json)。

Qwen3当前的结论标签命中最高。Qwen2.5主要受到大量弃答影响，InternVL的Agent主要受到未提交结论影响。Qwen3.5仍未完成全量，不能把这一子集当作最终排名。三个设置的提示、历史及输出形式不同，分数差也不能直接解释为搜证收益。
