# Decisions 的多轮搜证版本

Decisions 可以选择程序提供的动作；程序执行工具后，将实际返回的文字和照片带入下一轮。此前实现只做直接三分类，把工具列留空是适配器范围的限制。[官方说明](https://developers.openai.com/api/docs/guides/decisions)。

## 动作从哪里来

public-menu-v1 每轮从公开会话构造最多 64 个具体动作：

- 请求照片：使用公开的物品、时点、视角组合；不读取材料实际是否存在或可提交。
- 检查、裁剪、放大和缩小：使用已释放图片及已有派生视图。裁剪提供固定分区和已有公开目标框；裁剪不会恢复遮挡。
- OCR、图像质量、元数据、双图比较，以及当前可用的三类 grounding。
- 结束：支持、反驳、需要更多证据。支持和反驳提供明确列出的来源区域引用，以及身份／时点关系选项；模型选择结论和引用组合。

新照片和裁剪图会出现在下一轮菜单。失败请求按环境原样返回，照常扣除工具成本。已有的检查记录与图片都保留。菜单不访问 Environment 的隐藏状态、源标签、充分性标注或资产目录。候选顺序采用固定种子并按轮次确定，不根据标签排序；保留完整菜单、选择、实际调用和返回，便于复核。

程序提供了参数和粗区域引用，因此减少了自由生成坐标、查询和格式的负担。这个差异必须体现在论文中，不能把菜单版本的提升全部解释为视觉或搜证能力提升。现有自由参数 Luna Responses 结果保留。

## 评测与费用

沿用冻结的 209 个案件族、同样的图像与工具、8 轮、8192 输入 token 和工具成本上限 12。先对固定的四个小 ID 案件族、四种材料版本做 16 次真实接口检查，然后评测全部 209 个 Sufficient 交互任务。原来 418 次直接判断结果保留，补做工具条件，不重新请求已完成的直接判断。

主表完整后，在同一拨款的余款内继续 209 个 Obtainable 交互任务，用来观察实际索证。该扩展不替换 Sufficient 主表、不改变分母；没有跑全则只报告完成数，不给缩小分母后的总体分数。模型可以直接停止，不强迫它索证或筛掉未使用工具的运行。

新增拨款最多 3.80 美元，包含试跑和扩展，受原来的 60 美元总账限制。没有足够剩余额度则不启动，不扩张到预留的 20 美元。Decisions 输入及重发历史计费，分类输出不计生成 token；模型实际输入 usage、时延与本地工具成本照常记录。

scripts/run_decisions_tools.py 使用独立冻结源码执行；scripts/score_api_results.py 只接纳完整固定题组。公开报告单独保存菜单版本来源，Table 1 将其工具结果与原直接判断合成一行并加注参数辅助差异。44 项离线检查已验证真实环境中的请求、裁剪、反馈、停止、旧分数保留和隐藏标签隔离；这些软件测试使用灰色图片，不作为研究结果。
