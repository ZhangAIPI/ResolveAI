# 证据充分性评分审计：题目、弃答与区域定位

本页解释冻结代码 `4810a1e` 的实际结果，不修改既有评测分数。标注状态为 `source-derived-unreviewed`：身份标签来自 CO3D 序列，区域来自来源前景掩码，尚未经过独立视觉审核。这里的“未通过充分性规则”不等于人工逐例认定模型没有视觉依据，也不能直接解释为视觉理解能力低。

## Qwen2.5 的 565 次弃答

Agent 共运行 1,200 个案件；565 个有效 finish 全为 Need more evidence，其余 635 个未完成有效提交，不能当作弃答。

| 版本 | 每版案件数 | 构造时给定的材料 | 按当前规则的目标 | 有效弃答 | 未完成 |
|---|---:|---|---|---:|---:|
| Sufficient | 300 | 两张指定原图已释放 | Supported | 213 | 87 |
| Obtainable | 300 | 原图 A 与 B 的 48 像素预览；B 原图可请求 | Supported | 118 | 182 |
| Missing | 300 | B 原图从材料库移除 | Need more evidence | 117 | 183 |
| Unavailable | 300 | B 原图存在但不可提交 | Need more evidence | 117 | 183 |

331 次弃答发生在按当前标注可支持的版本；234 次发生在预设缺材料的版本。Obtainable 的 300 案件中，17 案件实际请求了照片，共 20 次请求；9 案件获得指定 B 原图。这说明当前策略没有充分使用材料获取机会，但不足以把所有失败归因于视觉模型。

Sufficient 是构造规则的结构性判断，尚非人工确认像素足以证明物理身份。题干只说“物体”，公开 object 字段只说 item，照片中可能有多个物体。预览 image_id 与原图 source_id 的关系也造成引用歧义。当前每族只标注指定 A/B 的充分链，替代视角和低分辨率预览是否也足够尚未审核；因此 Missing/Unavailable 不保证观察者真的无法判断。

## InternVL 的 55 个确定结论

Agent 共运行 1,200 案件，55 个有效 finish：47 个 Refuted，8 个 Supported；其余 1,145 个未完成。

- 47 个 Refuted 与来源推导的正身份标签相反；其中 31 个同时提交 same_object 关系，在当前单一身份声明中与 Refuted 自相矛盾。
- 8 个 Supported 的类别结论与标签一致，但两端的区域框均未达到 IoU 0.5，未通过指定区域链匹配。

因此应表述为“55 个都没有通过当前自动充分性协议”，不能写成“人工确认 55 个都没有依据”。结论错误、区域定位错误和协议错误必须分开报告。

## 判分规则

1. finish 引用必须是已释放的图片 ID、合法原图像素框及公开时点；违规调用返回错误，模型可在六轮限制内重试。
2. 身份链必须提交 same_object/different_object 等跨图关系；图片 ID、时点、关系均须与已标注链匹配。same_object 允许交换左右端点。
3. 两端引用框各自与来源目标框的 IoU 至少为 0.5。IoU = 相交面积 / 合并面积。
4. 支持合取声明须覆盖全部子声明；反驳允许一个可靠的决定性反例。多余但不匹配标注的关系也会使链检查失败。本轮主数据只有身份子声明。
5. 总代理分要求类别符合完整可获得材料库的目标，并通过合法引用和充分链检查。Need more evidence 在预设无法获得指定链时可计分；未完成计零。弃答不要求证明已穷尽请求，因此必须同时报告确定结论覆盖率。

这是规则评分，不是另一个 VLM 读解释后打分。完整材料库的目标由标注链所需图片是否可获得推导，未进行逐案像素充分性判定。严格的整物体 IoU 是定位代理，可能排除足够支持身份的局部纹理引用；不能把该代理当成完整的语义证据审查。

## 实际题目与失败例

椅子案件 `co3d-b92a229755096225bd9b-Sufficient` 的原题：

> The objects in photo-e8ccc6419301f416c031 and photo-82a2bbd89da1e7ff9029 are the same physical item.

模型看到椅子的不同视角，以及图片 ID、camera_view、capture 时点、原图尺寸和公开坐标映射；看不到目标框、身份真值或未释放图片。Agent 可逐轮检查、裁剪、比对、请求照片，最后提交三分类结论、区域引用和关系；预算 12、最多 6 个 assistant 回合。

杯子案件 `co3d-10847a0851dcd57276e1-Sufficient` 的照片同时有杯子、杯盖和大凳子，而声明仅说“物体”。InternVL 经 compare、crop、crop、compare 后提交 Supported 和 same_object，两个引用框都是 `[200,100,400,300]`。来源杯子框分别为 `[317,65,397,140]`、`[306,107,405,193]`，IoU 为 0.075、0.200；所以类别结论正确而区域链失败。题目目标指代不清是这里真实存在的数据问题。

主候选集为 6 类、300 个序列、1,594 张原图、四种材料版本共 1,200 案件；并非 1,200 个独立实物。目前只有来源推导的正身份声明，还没有身份硬负例或真实前后损坏声明。

## 下一轮需要修正的边界

- 在公开题干中明确待验证目标，例如“图 A 的红色杯子与图 B 的红色杯子”；不泄漏身份答案，也不提供私有缺陷框。
- 独立审核身份可判断性、低分辨率材料和替代充分链；不把指定原图缺失机械等同于没有证据。
- 分开报告有效提交率、结论类别正确率、定位 IoU、证据链充分性和材料获取收益。
- 先在独立开发集修复原图/预览引用和输出格式；已有 v0.3 小规模配对检查未提高 Agent 代理评分，不能声称接口修正已经奏效。

完整三模型结果见 [汇总](co3d_candidates.md)；原始分数保留其冻结协议和未审核限制，当前不构成训练收益验证。
