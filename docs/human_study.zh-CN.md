# 20 人短版人工实验：中文 / English

每人预计 5–10 分钟，共 5 道题。没有倒计时、点数或操作次数限制，只记录操作和实际用时。页面顶部可切换中文／English；切换保留选图和未提交理由。

## 发给参与者

在研究者入口复制 20 条邀请，每人一条，不要多人共用。参与者不用注册、填写姓名或上传图片。推荐电脑浏览器。

> 请独立完成这 5 道图片判断题，预计 5–10 分钟。点击图片选作依据，在图片下方放大、缩小或裁剪，需要时请求其他照片。每题只提交一次；看不清或证据不足时选“无法确定”。没有时间和操作次数上限，请不要与其他参与者讨论。用自己的邀请链接打开即可。

研究者入口另有“试用新版流程”链接。它使用**独立数据库**，可用于测试页面，不占用正式邀请，也不会进入正式统计。已经完成的 P01 旧记录保留，不覆盖或补造答案。

[公开说明页](https://pathology-decision-solved-mood.trycloudflare.com) 不含个人邀请密钥。当前隧道预计到 **2026 年 10 月 9 日 00:16（美国东部时间）**；重启后地址可能变化，已保存回答仍留在 p62。

## 五题怎样走

前三题是搜证：分别只提供初始材料、允许索取材料、提供全部可获取材料。三种条件的顺序按人随机；每种条件的图片都可放大、缩小、裁剪、比较或 OCR。只有允许索证的那题能请求额外材料。

后两题是独立图片审核：开始就显示完整可获取材料，同样能操作图片，选择结论与依据，**一次提交完成一题**。不再为同一声明重复五轮提问。每次“下一题”都进入另一个案件；题目文字可能相似，但不会是同一来源实物。

![中文页面](demo/assets/human-study.png)

[英文页面](demo/assets/human-study.en.png)

所有图片以正常查看尺寸显示。48 像素的低清照片也会显示得足够大，并标注清晰度；显示放大不会制造新的细节。真正请求到清晰原图后，原图替换同一来源的低清照片，不并列堆叠一大一小。不同实拍视角保留各自图片。

放大／缩小是浏览器显示操作：记录为 `presentation_only`，不重采样图像、不算作新增证据。裁剪和 OCR 仍使用已释放像素，坐标保留源图映射。裁剪后可在“更多”恢复已释放整图。正常参考是另一个实物，不能当作目标的“之前照片”。

页面截图使用正式 20 族之外的示例，测试回答没有写入正式库。截图内 MVTec AD 图片及衍生展示使用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)；见 [官方数据条件](https://www.mvtec.com/research-teaching/datasets/mvtec-ad) 和 [来源、校验及浏览器验证记录](results/human_web_smoke.json)。数据许可和代码分别处理。

## 抽样和统计

从 478 个声明组合、1,912 个释放配置中预先抽取 20 族：10 个状态声明、8 个身份正负控制和2个同类别身份未知候选。来源标签不直接当成真实身份标签。

其中 10 族用于搜证，每种条件各有2人回答，共60次。全部20族每族有2份独立审核，共40份。每人的五题不共享目标原图或多视角序列，也不审核自己搜过的物品。题单保持冻结，UI修复不重抽已分配案件。

新版审核记录为 `visual-truth-review-v2`：完整材料的结论、声明清晰度、证据区域或身份对应，以及理由。两位不同审核者都认为题目清楚、结论一致且引用合法后，报告完整材料下的结论一致率。不同意见保持待审。

**这份单次审核没有询问四种版本各自的初始／可获取池是否充分。** 分析程序不能据此自动生成这些标签，也不能宣称完整的搜证、无依据决策或 grounded accuracy 已获独立审核。完整材料的模型对照仅统计实际可见图片池与审核完全一致的直接多图模式。完整的充分性协议仍需另行审核。旧五阶段 `visual-review-v1` 记录单独处理，不用新版记录填补缺项。

三个模型的冻结题单包含这20族，模型代码保持 `5dc8125`，不随人工UI改动。人工不限次数、默认显示放大，工具与模型预算也不同，本次不用于同预算人机能力排名。先看人能否判断，再看相同完整材料下模型是否判断失败；这样才能区分题目问题和模型问题。

## 运行和结果

代码在GPU节点 sclera 的 p62 上；网页使用CPU。权重、图片、轨迹、邀请密钥和个人回答都留在运行目录，不提交Git。

```bash
python -m resolveai.human_study /private/human-study-short-v2 --port 8765
python scripts/analyze_human_study.py /private/human-study-short-v2 \
  /private/evaluation/human-study-v2 /private/new-analysis-snapshot
```

研究者入口可查看进度，下载匿名记录和审核JSONL。分析写入新目录，完整材料一致率和严格充分性评分分开报告；未通过独立审核时不产生正式分数。

当前UI协议为 `human-ui-v4-single-answer`。浏览器测试使用P01相同五题，但在临时库里完成，验证低清图正常大小显示、五题都有操作、确定结论后一题结束，以及试用与正式数据隔离。见 [浏览器记录](results/human_web_smoke.json) 和 [上线检查](results/human_web_deployment.json)。
