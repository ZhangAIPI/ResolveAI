# 后续五轮完整审稿、rebuttal 与修改（Round 4–8）

承接 [前三轮记录](reviews.zh-CN.md)。这是同一作者侧工具执行的顺序自审，不是五位独立专家。每轮均覆盖方法、创新边界、叙事、文字、图表、数据、指标、复现和限制；rebuttal 逐条区分文稿修正与仍待实验的问题。Recommendation 按当前稿件作为完整投稿判断，不假定未报告的结果。

## 写作参考的重新阅读

本次重新阅读了 MMMU、MMVP、BLINK、OpenEQA、VidComposition、MMPerspective、VSI-Bench、AVerImaTeC 的摘要，并阅读 [Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385) 的正文论证与方法、对照安排。

| 参考 | 本稿采用的写作判断 |
| --- | --- |
| [MMMU](https://arxiv.org/abs/2311.16502)、[BLINK](https://arxiv.org/abs/2404.12390) | 先说清具体评测能力和题目来源，数量服务于贡献，不代替贡献。 |
| [MMVP](https://arxiv.org/abs/2401.06209)、[VSI-Bench](https://arxiv.org/abs/2412.14171) | 从一个明确的能力问题推进到能区分解释的测试；不能借用其已验证的发现充当自己的结果。 |
| [OpenEQA](https://open-eqa.github.io/)、[AVerImaTeC](https://arxiv.org/abs/2505.17978) | 任务定义、证据来源与评价标准必须连在同一论证中。 |
| [VidComposition](https://arxiv.org/abs/2411.10979)、[MMPerspective](https://arxiv.org/abs/2505.20426) | 具体子任务承担能力划分；不复制泛泛的进展和意义开场。 |
| ResNet | 学习围绕一个问题推进、用简洁定义引出受控比较的组织方式。其经验性结论不能移植为本稿尚未完成的发现。 |

没有复制上述文章的句子或图片。

## Round 4

### Summary

稿件用同一视觉事实的证据访问变体研究搜证。整稿已区分取得充分证据与结论有依据，但预算内可达性仍不完整；引言主要用未联合实例化的身份加损坏故事，摘要仍接近功能清单。

### Strengths

- 固定事实、变化访问条件能在案件内检验“应判断”与“应保留”的差别，研究问题明确。
- 充分性定义与来源保留规则使实际取得的材料可以核查，模型辅助输出没有被当成身份真值。
- 题库状态、直接/交互输出差异、公开来源限制已有披露；主文和附录职责较清楚。

### Weaknesses

**Major**

- **R4-W1：** 无独立充分性审核及有效性结果，无法支持完成的 benchmark 贡献。
- **R4-W2：** 单张材料可请求，不代表一组充分材料能在总费用和回合数内共同取得。原有“可获得池”没有精确定义这个区别。
- **R4-W3：** 引言仍依赖未联合测试的身份与损坏例子；摘要按功能逐项介绍，没有把最终答案为何不足以评估搜证讲清楚。
- **R4-W4：** 降低预算时，超预算的可达证据不能被重新解释为物理上缺失；否则预算曲线会改变题目含义。

**Minor**

“缺关键照片”容易被读成只有一个正确下一步。数学定义、图中的动作选择和入库条件应允许替代充分路径。完整实验仍需匹配格式与输入条件。

### Questions

1. 充分证据集合能否在公开请求字段、工具费用和回合限制下共同取得？
2. 预算改变时，如何区分搜索困难与任务根本不可行？
3. 若只读摘要和图 1，读者能否说出评测最终答案之外新增测量了什么？

### Limitations and data attribution

公开数据仍分别测试状态和身份，不能推出联合状态变化能力。照片来源和许可保留；没有新增人工或模型分数。

### Recommendation

**Reject。** 候选题库的科学有效性尚无证据；预算可达性与叙事范围还需修正。

### Confidence

**High** 对稿件内可核查的问题；对未测量的任务难度保持有限判断。

## Round 5

### Summary

整稿围绕配对访问设计，数据构造、充分性和动作对照已接成一条论证，但诊断还过度依赖“交互失败、全池成功”的跨设置差异。该差异不等于搜证能力差。

### Strengths

- 身份开场与真实候选范围一致，正文三个 section 及图文叙事较集中。
- 预算可达性、公开请求字段、替代充分路径已有明确约束。
- 原图、裁剪和新视角的关系可追溯；生成图不能成为实证，工程设置在附录。

### Weaknesses

**Major**

- **R5-W1：** 全池输入可能增加干扰，直接与交互还有输出长度差异，不能仅靠这组分数定位搜证瓶颈。
- **R5-W2：** 尚缺从同一次轨迹分离“取得充分材料”和“正确使用材料”的可核查统计。
- **R5-W3：** 人工审核、有效性实验和相关工作的实证差异仍缺失，全文不能作为完成的 benchmark 投稿。

**Minor**

家庭级指标与平均分的关系需保留，但不必占据正文主要诊断公式。运行错误不能从分母移除；条件指标在零分母时需说明。

### Questions

1. 不改变输入设置，能否直接从轨迹判断证据缺口是否关闭？
2. 取得证据后的失败是否也包含引用和格式错误？
3. 始终弃答和根本未提交答案如何区分？

### Limitations and data attribution

证据取得依赖独立充分性标注，不能用源标签替代。公开数据、原始照片归属、许可及模型配置披露保持完整；未产生新实验分数。

### Recommendation

**Reject。** 定位方法仍需完善，且没有经审核的数据和有效性证据。

### Confidence

**High** 对计数和归因问题；对模型真实能力无结果可判断。

## Round 6

### Summary

本轮检查完整稿件的科学定义与实际评分是否一致。正文允许多条充分路径，但附录自动匹配器可能只认可已登记的区域与关系；这会把参考答案不完整误当成模型搜证失败。

### Strengths

- 同轨迹分解能够将开放的证据缺口与后续失败分开，避免仅凭跨输入分数归因。
- 引言、配对访问、充分性、数据审核和诊断顺序连贯；三幅主图与定义对应。
- 预算、可见像素、来源映射和未知标签的边界明确，代码实现细节留在附录。

### Weaknesses

**Major**

- **R6-W1：** 列举最小充分集合不保证穷尽所有正确依据。只认固定区域或关系可能误罚合理答案。
- **R6-W2：** “引用不匹配”与“证据确实不充分”没有完全分开，可能夸大 unsupported decision rate。
- **R6-W3：** 尚无独立标注、替代答案挑战审核和有效性结果，无法判断题库是否测量了预期能力。

**Minor**

全图引用覆盖目标区域不等于精确定位；额外关系的匹配失败可能涉及格式、无关关系或事实错误，应在报告中区分。正文不宜展开匹配器工程细节。

### Questions

1. 模型找到未预标的新路径怎么办？
2. 更新参考后，是否对所有模型统一重评分？
3. 怎样区分未提交、格式无效、证据待审核和证据已确认不足？

### Limitations and data attribution

照片、裁剪和元数据的边界已披露；公开来源仍不能提供未拍摄的时间变化。本文修改评分要求，没有实施新的人工裁决或改变正在运行的评测代码。

### Recommendation

**Reject。** 参考集合是否完整与评分是否偏置尚无证据。

### Confidence

**High** 对匹配规则的局限；人工裁决一致性尚无法判断。
